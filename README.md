# my-mon-pipe

Unified data pipeline for money-market and Federal Reserve balance-sheet work. R 4.5.2, no API keys,
no packages beyond tidyverse / httr / readxl / jsonlite / lubridate.

## Conventions (non-negotiable)

- **Dollars in millions of USD** (`usd_mn`). **Rates in basis points** (`bp`). Conversions happen once, at load,
  with the multiplier in `config/series_registry.csv`. No loader contains a divisor.
- **Business days only** for every daily series: inner join to `data/calendar` (NY Fed EFFR publication dates,
  from 2000-07-03). Month, quarter and year ends are the last business day on or before the calendar end.
- **Core is weekly** on the H.4.1 grid: nominal Wednesdays from 2002-12-18. Daily series enter core twice,
  as `WL` (value on the Wednesday-level date) and `WA` (mean over the business days Thu..Wed). H.4.1's own
  week averages are 7-calendar-day averages; ours for rates are business-day averages.
- **Latest vintage only.**
- **No silent splice of indicative history.** The legacy pipe warns on load; `splice_indicative()` is the only
  join and flags every row. FRED's SOFR averages/index are already spliced upstream and are not pulled.

## Pipes and outputs (`data/`)

| Output | Pipe | Content |
|---|---|---|
| `calendar` | - | daily, 2000-07-03 ->: `is_bday`, `week_wed` (H.4.1 week id), `wl_date`, first/last business day of month/quarter/year, `week_has_*_end`, `event` |
| `core_weekly` | core | 17 H.4.1 lines (WA+WL) + total assets; EFFR, OBFR, SOFR; targets; IOER/IORR/IORB; ON RRP rate; primary credit rate; overnight ON RRP and repo amounts; composites `target_top`, `target_bottom`, `ior` with a `source` column |
| `core_quarterly` | core | nominal GDP and CBO nominal potential GDP as published (quarter-start dated, projections kept). Align with `align_quarterly()` |
| `aux1_distributions` | 1 | NY Fed API: EFFR, OBFR, SOFR, BGCR, TGCR daily: rate, p1/p25/p75/p99, volume, target range, intraday range, std dev, revision flag |
| `aux2_h41_rest` | 2 | every other H.4.1 Table 1/1A/5 line, weekly; H.3 reserve balances (separately named) |
| `aux3_debt_h8` | 3 | FRED debt aggregates (quarterly), MSPD table 1 via FiscalData (monthly, `mspd_*`), H.8 weekly and monthly |
| `aux4_treasury_rates` | 4 | DGS1/2/5/10, DFII10, DTB4WK/3/6 daily; TB3MS, GS10 monthly |
| `aux5_operations`, `aux5_rrp_by_counterparty` | 5 | NY Fed API operation-level repo/RRP results and ON RRP by counterparty type (wide; `($Billions)` -> `(usd_mn)`, `(%)` -> `(bp)`) |
| `legacy_indicative` | legacy | `ind_tgcr`, `ind_bgcr`, `ind_sofr` (rate, volume), `ind_effr_brokered` (p1..p99, volume), `ind_sofr_averages` (avg30/90/180, index) |

All long tables share the schema `date, series, stat, value, unit, source`. `data/raw/` keeps every download as received.
`data/build_log.txt` lists each series with first/last date, count and unit.

## Run

```
Rscript scripts/make_core.R        # calendar + core only (seconds)
Rscript scripts/make_all.R         # everything, then tests
Rscript tests/run_tests.R          # tests only; add --units to re-check FRED unit strings
```

## Using core

```r
options(mmp.root = "C:/Work/WorkGit/my-mon-pipe"); for (s in list.files("R", full.names = TRUE)) source(s)
core <- readRDS("data/core_weekly.rds"); cal <- readRDS("data/calendar.rds"); q <- readRDS("data/core_quarterly.rds")
wl   <- core_wide(core, "WL")                                   # one column per series, Wednesday levels
gdp  <- align_quarterly(q, wl$date)                              # linear, mid-quarter anchors, tail at potential growth
gdp  <- align_quarterly(q, wl$date, method = "step")             # as published, no interpolation
```

## Config

- `config/series_registry.csv` is generated by `scripts/build_registry.py`; edit the generator, not the CSV.
- `config/events.csv` seeds the event table (TODO, on hold: FOMC dates, policy changes, recessions, facilities).
- `config/calendar_exclusions.csv` lists dates FRED carries but the NY Fed never published (verified against the
  Markets API; currently 2002-02-18, Presidents Day, where FRED repeats the Friday EFFR).
- `config/static_files.csv` + `static/` hold the three NY Fed legacy workbooks with their MD5s.
- `config/h41_split.md` documents the core vs aux2 split of H.4.1.
